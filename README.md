# 🚀 TechMach AI Mock Test Platform

**Practice. Test Your Knowledge. Improve Your Score.**

TechMach Mock Test is a modern, interactive web-based practice platform designed for **Computer Science students and competitive exam aspirants**.

It provides exam-style mock tests with timed assessments, negative marking, question navigation, performance tracking, and detailed answer review.

## ✨ Features

* 📝 Multiple Computer Science & competitive exam mock tests
* ⏱️ Timed examination experience
* ➖ Negative marking support
* 🔀 Question & option shuffling
* ⭐ Mark questions for review
* 🧭 Question palette for quick navigation
* 📊 Score & accuracy analysis
* 📈 Best score and average score tracking
* 🔍 Detailed answer review
* 💾 Local progress/statistics storage
* 📱 Responsive design for desktop and mobile
* 🎯 STET & subject-wise practice tests
